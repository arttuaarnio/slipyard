Add paging to the list command: `python3 -m bookmarks list --limit N --offset M` shows at most N bookmarks after skipping the first M, in id order and the normal list format. Both are optional: no --limit means no limit, and --offset defaults to 0. --limit must be at least 1 and --offset at least 0; anything else is a usage error (exit code 2, message on stderr, nothing on stdout). An offset past the end prints nothing and exits 0.
